# AsOf — открытый API и формат паспорта

**AsOf** (Diikun LAB) — публичный архив только для чтения: *что стоит за токеном на конкретную дату*. Для каждого токена AsOf фиксирует, что говорят документы самого эмитента по четырём вопросам. У каждого утверждения есть дословная цитата, источник и дата.

| Слой | Вопрос |
|---|---|
| Юридический | Кто должен держателю? Кто эмитент, какое право и лицензия? |
| Выход | Как выйти: погасить, с каким минимумом и комиссиями, когда погашение могут приостановить? |
| Обеспечение | Чем обеспечен токен, кто это хранит и кто проверяет? |
| Правила | Кто может заморозить, выпустить новые токены, заменить контракт или изменить условия? |

На что документы не отвечают, показано как **«Неизвестно»** — не скрывается и не оценивается. Данные из блокчейна (выпуск, обновляемый прокси, ключи администраторов, роли паузы и блокировки) читаются напрямую, с номером блока.

Здесь публичная часть AsOf: документация API, открытый формат паспорта и примеры для сравнения токенов и контроля изменений.

🌐 Сайт: **https://asof.pro** (пока также https://asof.diikunapp.workers.dev) · 🇬🇧 [English](README.md)

## Быстрый старт

Ключ и регистрация не нужны. Файлы можно читать с любого сайта (CORS) или сервера.

```bash
curl https://asof.diikunapp.workers.dev/api/v1/passports/paxg.json
```

| Адрес | Что отдаёт |
|---|---|
| `/api/v1/index.json` | все активы, счётчики, время последнего прогона |
| `/api/v1/passports/{id}.json` | паспорт: факты с цитатами и источниками, данные из блокчейна, архив источников, «Неизвестно» |
| `/api/v1/changes.json` | найденные изменения в документах эмитентов (короткие фрагменты) |
| `/api/v1/schema.json` | JSON Schema формата |
| `/feed.xml` | лента изменений (Atom) |

Активы сейчас (20): золото — `paxg`, `xaut`; долларовые стейблкоины — `usdt`, `usdc`, `pyusd`, `rlusd`, `usdg`; евро-стейблкоины — `eurc`, `eurcv`; фонды и ноты — `benji`, `ustb`, `uscc`, `usyc`, `ousg`, `usdy`; криптотокены — `uni`, `link`, `steth`, `ena`, `aave`. Актуальный список всегда в `/api/v1/index.json`. Подробно: [docs/api.md](docs/api.md) · формат: [docs/format.md](docs/format.md).

## Что можно сделать

- **Сравнение** двух токенов по каждому вопросу (PAXG и XAUT; USDT, USDC, PYUSD и RLUSD; EURC и EURCV): `python3 examples/python/compare.py paxg xaut`
- **Контроль** токена, который вы держите или листите. Пример сообщит, если:
  - появился или исчез факт;
  - цитата пропала из документа эмитента;
  - источник перестал отвечать;
  - сменился админ прокси, владелец или код контракта;
  - контракт поставлен на паузу.

  Команда: `python3 examples/python/monitor.py usdc`. Код выхода 1 означает, что что-то изменилось. Есть пример для GitHub Actions.
- **Встраивание** карточки паспорта на свой сайт: [examples/embed/index.html](examples/embed/index.html).
